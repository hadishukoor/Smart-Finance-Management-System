1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
The Smart Finance Management System is a state-of-the-art fintech web application engineered using the Laravel PHP framework. It securely handles user authentication, tracks dynamic personal expenses, calculates analytical spending patterns, provides AI-level algorithmic savings
recommendations based on a 50/30/20 structural rule, and maps real-time Indian stock market investments using live JSON data explicitly scraped from Yahoo Finance APIs.

The application has been completed "until now" with fully functional controllers correctly enforcing business logic, database relationships, and real-time market API requests.

2. COMPREHENSIVE FEATURE LIST (HONEST ACTUAL IMPLEMENTATION)
--------------------------------------------------------------------------------
- Custom High-Fidelity Authentication: Implemented transparent entry gates mapping directly to Laravel's standard Auth patterns (AuthController).
- Complete CRUD Expense Tracking: Real-time creation, updating, reading, and deletion of expenses, fully locked per-user.
- Deep Financial Analytics Engine: Detects the highest spending category natively (e.g., highlighting out-of-control spending).
- Month-over-Month Delta Tracking: Analyzes Carbon-based time periods to compare current monthly spending physically against the previous 30 days.
- CSV Data Archiving: A stream-based native exporter (`export()`) instantly generates properly formatted `financial_report_{year}_{month}.csv` files dynamically.
- 50/30/20 "Smart Goals" Bucket-List Engine: Computes exact 50%, 30%, and 20% salary splits, mapping remaining months to target dates. Systematically warns the user if saving for a target breaches their 30% discretionary budget boundary.
- Live Algorithmic Stock Portfolio Tracker: Users can add NSE (Indian) stocks. The system automatically fetches prices by appending `.NS`.
- Instant Live Price Synchronization: The `syncAll()` loop systematically pings Yahoo Finance to dynamically update the `current_price` and `previous_close` of all user holdings seamlessly.
- Smart Investment Advisor: Suggests Mutual Funds/SIPs or Direct Equities dynamically based on the user's exact current monthly savings buffer.
